# Changelog

## 1.0.0-rc.1 — 2026-10-05

- Standalone NYRC identity, original expressive SVG character, local-first onboarding and unified assistant.
- Local utilities, timers, durable reminders, aliases/modes, Pocket, permissions, optional cloud adapters and Google Calendar.
- Host-owned Body API, virtual-body simulator and bounded authenticated loopback protocol.
- Transactional migration, secure credential store, filesystem jail, cancellation/race protection and single-storage-instance guard.
- Backend native confirmation, stale provider rejection, bounded queues and durable reminder recovery hardened in Prompt 4.
- Consistent RC version/About/diagnostics, four-target packaging CI, checksums/provenance, optional signing paths and release/privacy/security documentation.

Unsigned/not-notarized candidates remain distinct from stable trusted distribution. Live external services, physical hardware and untested native OS behavior are identified in the release scorecard.
