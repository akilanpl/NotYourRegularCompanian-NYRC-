# NYRC presentation

The original compact ceramic shell encloses a dark glass face. Two OLED-friendly apertures and a single status bar form the identity; there is no inherited raster artwork.

`styles.css` defines graphite surfaces, cool white hierarchy, muted blue accent, status colors, spacing, radius, blur, motion, shadow and layering. CharacterRenderer consumes semantic expressions only. BodyCore remains authoritative for reactions and external presentation.

Motion is event driven. Blink runs at 5.7 second intervals only in focused visible windows; reduced motion disables transitions. Expression gestures run a bounded number of cycles. The assistant has bounded recent task context, scrollable action cards and equal permission choices.

Settings separates product NYRC from user-chosen instance names. Secrets are write-only and stored in the operating system keychain. Local-only is the default.
